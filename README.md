## Application

The maintained product is a Next.js/React application backed by PostgreSQL
and Prisma. It includes the editorial site, series database, administration,
automated news pipeline, media storage integrations and advertising stack.

Run and deployment commands are documented in
[`serien-nextjs/README.md`](./serien-nextjs/README.md). Never copy credentials
from historical documents or Git history into a new environment.
